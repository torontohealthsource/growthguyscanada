Why the sub-98% reports are the part worth reading

A published set with no low results is a curated set. Purity assays on peptides do not all land in the same place: synthesis, purification and storage each move the number, and a catalogue of 132 products tested repeatedly will produce a distribution, not a flat line. When every published figure sits above 99%, the likeliest explanation is that the ones below it were not published.

Thirty-two results under 98% sitting on the vendor's own page is therefore the more useful signal, and it is the one most buyers skip past. It means the page is a record rather than a highlight reel, which is what makes the 99.03% mean worth anything in the first place.

Where the report resolves, and why that matters more than the figure

Each report opens on Janoshik's own portal, under the lab's reference, naming the client and the batch. That is the part to check. A certificate hosted only as a PDF on a seller's own server carries no independent confirmation — the file can be edited by whoever serves it, and a number in a PDF proves nothing about the vial.

The practical test is to take the batch code from the product page, open the report from the lab's domain rather than the vendor's, and confirm the batch and client names match what you were shown. If a report will not resolve on the lab's own system, the purity figure attached to it should be treated as a claim rather than a result.

Reading a batch code against what you received

Batch codes in this set follow a short product-plus-number form — KPV04 and TB09 are typical. The code on the vial should match the code on the report, and the report's test date should precede the date the batch was listed. A report dated after the listing usually means the batch was tested retroactively, which is weaker evidence than a pre-listing test.

Where a product has been re-made, there will be several reports under the same product name with different batch codes. Those are separate results and should be read separately; an average across a product's history tells you about the vendor's process, while the specific batch code tells you about the vial in front of you.
