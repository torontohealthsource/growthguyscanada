Two discount codes do not stack, and the failure is silent

You can use one discount code per order. Attempting a second does not produce an error explaining what happened — the store simply does not apply it, and the cart total stays where it was. That silence is the practical problem, because it looks identical to a code that has expired.

We know the behaviour because our own daily cart testing has to work around it. A code tested on a cart that still held another would be recorded as dead when it is perfectly valid — which is almost certainly what has happened to people who concluded a code was broken.
