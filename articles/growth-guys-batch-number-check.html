What the batch code is, and how many of the reports carry one

The format is consistent: a short letter prefix tied to the compound followed by a sequence number, which is how 230 of those 238 are written. Codes such as RET28, TB09, GGC42 and CJCIPA05 are typical — the letters identify the product line, the digits identify which run of it was tested.

The code is the only thing that links a specific vial in your hand to a specific document on a laboratory's server. What it means when your batch is not in the published set

A published set is a snapshot, and stock moves faster than documents get posted. A batch that is not listed is most often simply newer than the last update to the page, which is a record-keeping lag rather than an untested run. It is not, by itself, evidence of anything wrong.

It is still worth resolving rather than shrugging at. Ask for the report covering that specific batch code. The question is reasonable and a vendor testing per run can answer it, because the document already exists. The answer you get is informative either way: a seller who tests per batch produces the report, and a seller who tested once and reused the certificate cannot.
