Where the 20%, 25% and 35% listings come from

Aggregator sites generate them. A template produces “up to 35% off” for every store in its database, and a code string to go with it, and neither is ever entered in a cart. They rank because they are numerous, not because they are true. A bigger number on a listing changes the listing, not the checkout.

Why every real code is 10%

The store sets one sitewide affiliate rate and issues several strings that reach it. The strings differ; the discount behind them is identical. So “best code” cannot mean “biggest” here. It can only mean the one with the longest unbroken, dated record of being tested — which is the reason this page exists.
