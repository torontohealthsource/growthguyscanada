The standard this page is built to, and why it matters more than the code

Any page can tell you a code works. Almost none tell you when they last checked, which makes the claim impossible to disprove and therefore worth nothing. A coupon listing that cannot be falsified is not evidence; it is an assertion with a number in it.

So the standard we hold ourselves to is narrower and duller than "verified", and it has four parts. A claim about a discount code is worth something only if: it is dated to the moment of the test; the cart value changes between tests, so a code that works only at one price point is caught rather than hidden; failures are published alongside passes; and the series is tamper-evident, so nobody — including us — can quietly rewrite a result after the fact.

That last one is the part nearly everyone skips, and it is the reason this page links a ledger rather than a screenshot. A screenshot shows that something appeared on a screen once. It cannot show that the record was not edited afterwards, and a reader cannot recompute it.
