The most common cause is an empty cart that does not look empty

Most products in the peptides category are variable products — they are sold in more than one packaging, typically a single vial or a 10-pack. A variable product does not enter the cart until a specific variant has been chosen. Miss that step and the store accepts the click, the page looks like it worked, and the cart stays empty.

A discount code applied to an empty cart cannot do anything, and the message you get does not say "your cart is empty" — it reads as the code failing. We reproduced this deliberately while building automated cart tests: 66 of roughly 90 products in that category could not be added without selecting a variant first. Before troubleshooting the code at all, confirm the cart line actually shows the item and a quantity.

One coupon slot, and it is occupied by whatever got there first

The store accepts one discount code per order. If another coupon is already applied — from an earlier session, a browser extension, or an abandoned cart you returned to — the one you are entering now will be refused, and refused silently. The total simply does not move.

Clear the discount field entirely, confirm no existing discount line is shown, then apply the code you want. Our own daily testing has to strip previously applied coupons before each run for exactly this reason: a leftover coupon makes a perfectly valid code look dead, which is almost certainly what has happened to most people who have concluded a code expired.
