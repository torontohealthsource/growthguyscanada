The conditions that decide whether a code works on your cart

A minimum is the most common condition and the easiest to miss, because a code that fails on a small cart and works on a larger one looks like an expired code to the person testing it.

Minimum spend

A minimum is the most common condition and the easiest to miss, because a code that fails on a small cart and works on a larger one looks like an expired code to the person testing it. Where a page states that there is no minimum, that is a specific claim worth more than a general one, because it is falsifiable with a one-item cart.

Product exclusions

Exclusions are usually category-level -- sale items, bundles, a particular range -- and they are the condition most often omitted from listings, because a listing that names exclusions is harder to write and less attractive to read. A code described as sitewide with no exclusions is making a strong and checkable claim.

One use, one account, one order

Single-use codes work once and then appear broken. Account-bound codes fail for guests. First-order codes fail for returning buyers. All three produce the same symptom -- a code that does not apply -- and none of them mean the code is dead.

Guest carts and signed-in carts differ

A code tested while signed in may behave differently for a guest, because account history, loyalty status and first-order flags all attach to the session. A test that does not say which it used has left out a condition that changes the answer for a large share of readers.

Stacking with other reductions

Whether a code combines with a sale price, a bundle price or a payment-method reduction is a per-store configuration, not a general rule. The only reliable way to know is to put both on a cart and read the total, which is why claims about combined figures should carry a cart.

Regional and currency conditions

A store serving several countries may run different codes per region, or honour one code at different values depending on the currency the cart is priced in. A listing that does not say which market it tested is describing a cart that may not resemble yours, and this is a common source of codes that work for some readers and not others with no apparent pattern.

Expiry, stated and unstated

Some codes carry a published end date; many simply stop. An undated listing cannot distinguish the two, which is why the date a claim was checked matters more than any expiry the page quotes.
