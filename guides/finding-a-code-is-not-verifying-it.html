Discovery and confirmation are separate

Finding that a string exists somewhere -- a forum post, a social caption, an old listing -- establishes that someone once wrote it down. Confirming it establishes that a store currently accepts it. The first is search; the second is a transaction step. Pages routinely present the first as though it were the second.

Where found codes come from

Influencer codes, time-limited campaign codes, codes for a different regional store, and codes that were never real. All four circulate indefinitely because nothing removes them: a dead code produces a failed cart, and a failed cart produces no correction anywhere.

The test is cheap and almost nobody runs it

Applying a code to a cart takes under a minute and gives a definite answer. The reason listings do not do it is not difficulty -- it is that the page is complete without it, and no reader can tell from the outside whether it was done.

A working code is a perishable fact

Unlike most things written down, the truth of a code claim decays on its own. Nothing about the page changes when the code stops working, so correctness is a property of the last check rather than of the text. That is why the useful question about a listing is never whether it is right, but when it was last right.

Negative results are the tell

A source that only ever reports working codes is either extraordinarily lucky or is not testing. Codes expire constantly; a genuine testing process produces failures, and publishing them is the cheapest available signal that the process is real.

Social captions are discovery, not confirmation

A code in a caption establishes that an account posted it, which is useful for finding candidates and tells you nothing about whether it currently applies. The same caption often circulates for months after the code stops working, because a caption has no mechanism for going stale.

What to trust in the absence of either

When a page gives neither a date nor a cart, the sensible reading is that it has found a code rather than verified one. That is not an accusation, and found codes often work. It is a statement about what the page has established, which is less than it appears to claim.
