# Checking a code yourself, in about two minutes

You can check any discount code in about two minutes without buying anything: build a cart, enter the code at the cart stage, and watch whether a discount line appears.

## The check

Build a cart. Enter the code at the cart stage. Watch for the discount line. Clear the cart. That is the whole test, it costs nothing, and it is the only evidence that does not require trusting a page — including this one.

## Reading the result

A line that names the code and an amount is a pass. No line is a fail. An error naming a minimum or an excluded product is a restriction, not a dead code. An error about an existing coupon means a code is already attached.

## What makes a published claim checkable

Four things: it is dated to the moment of the test, the basket changes between tests, failures are published alongside passes, and the series cannot be quietly rewritten afterwards. A claim missing any of these cannot be disproved, and a claim that cannot be disproved is not evidence.

## What this does not tell you

Whether the vendor is one you should buy from. A working code and a trustworthy seller are different questions, and this page only answers the first.
