Read a published lab set for its worst result, not its average. A set with no weak results in it has been filtered, and tells you about the filter rather than the products.

Filtering is invisible from the inside

A seller choosing which reports to publish can produce a flawless record without falsifying a single document. Every report is genuine; the set is not. And a filtered set tells you about the filter, not about the products.

So read for the floor, not the average

The useful question is not the mean but the worst published result. In this vendor's set of 240 reports, 33 come in below 98% and the lowest on record is 93.844%. Those sit alongside the strong ones.

What a visible floor is evidence of

Not quality — a low result is a low result. It is evidence about the publishing policy: a set with a visible floor has not been groomed, which makes every other number in it worth more than the same number in a flawless set.

What this does not tell you

Whether anything unpublished exists. A visible floor is consistent with full publication and also with partial publication that happens to include some weak results. It raises the floor of what can be claimed, not the ceiling.

What a floor is not evidence of

A visible worst result shows the set was not groomed. It does not show the set is complete. Both a fully published record and a partly published one that happens to include some weak results look the same from outside, and nothing a reader can do distinguishes them. The honest claim is therefore narrow: a floor raises what can be said about the publishing policy, and says nothing about what was never published.
