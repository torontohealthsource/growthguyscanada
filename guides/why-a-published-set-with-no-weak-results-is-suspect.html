A published set with no failures has been filtered

Read a published lab set for its worst result, not its average. A set with no weak results in it has been filtered, and tells you about the filter rather than the products.

Filtering is invisible from the inside

A seller choosing which reports to publish can produce a flawless record without falsifying a single document. Every report is genuine; the set is not. And a filtered set tells you about the filter, not about the products.

So read for the floor, not the average

The useful question is not the mean but the worst published result. In this vendor's set of 244 reports, 33 come in below 98% and the lowest on record is 93.844%. Those sit alongside the strong ones.

What a visible floor is evidence of

Not quality — a low result is a low result. It is evidence about the publishing policy: a set with a visible floor has not been groomed, which makes every other number in it worth more than the same number in a flawless set.

What this does not tell you

Whether anything unpublished exists. A visible floor is consistent with full publication and also with partial publication that happens to include some weak results. It raises the floor of what can be claimed, not the ceiling.

What a floor is not evidence of

A visible worst result shows the set was not groomed. It does not show the set is complete. Both a fully published record and a partly published one that happens to include some weak results look the same from outside, and nothing a reader can do distinguishes them. The honest claim is therefore narrow: a floor raises what can be said about the publishing policy, and says nothing about what was never published.

How large a set has to be before absence means anything

The inference needs scale, and applying it to a small set punishes a seller for being new rather than evasive. Three published results that are all strong is an unremarkable outcome. Across a hundred-plus products tested repeatedly, synthesised at different chain lengths and difficulties, a complete absence of anything mediocre becomes genuinely improbable. Before asking whether a set looks curated, check whether it is large enough and varied enough for the question to have an answer at all.

The symmetrical error

A set containing weak results is not thereby a good set — it is an unfiltered one, and an unfiltered record of poor material is exactly as discouraging as it reads. The absence of filtering makes the numbers trustworthy; it does not make them favourable. Read the distribution first to decide whether the figures can be believed, then read the figures to decide what they say. Collapsing those two steps is how 'they publish bad results, so they must be honest' becomes an argument for buying something you should not.

What to do with the conclusion

Having decided a set looks unfiltered, the next step is not to relax but to read it. The spread tells you what range of outcomes the seller actually produces, and the low end of that range is the realistic worst case for anything you order. That is more useful than the average, which describes a vial you are unlikely to receive specifically. A record worth trusting and a record worth being pleased about are two separate findings, and the first has to be settled before the second means anything.
